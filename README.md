## ⚙️ Run locally

This is a static website. No build setup is required.

```bash
git clone https://github.com/Shivam-Sharma2009/shivam-portfolio.git
cd shivam-portfolio
```

Open `index.html` in your browser, or launch it with VS Code **Live Server**.
