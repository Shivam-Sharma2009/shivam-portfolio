## About this portfolio

The portfolio is built with:

- **HTML5** for semantic page structure
- **CSS3** for responsive layouts, styling, and animations
- **Vanilla JavaScript** for interactive elements
- **Font Awesome** for icons
- **Google Fonts (Inter)** for typography

### Highlights

- Responsive layout with mobile navigation
- About, skills, interests, projects, and contact sections
- Animated UI elements and scroll interactions
- Live local-time flip clock
- Contact form interface
- Resume page

## Run locally

No build tools are required.

```bash
git clone https://github.com/Shivam-Sharma2009/shivam-portfolio.git
cd shivam-portfolio
```

Open `index.html` in your browser, or use the VS Code **Live Server** extension.
